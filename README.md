# ListIt 🥕
https://list-it-ten.vercel.app/

A grocery list app with multi-user accounts, built with JavaScript and Supabase.
## Features

- Email/password sign-up and login (Supabase Auth)
- Add items with a category (Produce, Meat & Fish, Dairy & Eggs, Bakery & Snacks, Beverages, Cooking Oil & Ghee, Chips & Crisps, Other)
- Adjustable quantities per item
- Check items off as you shop, with a live progress bar
- Clear checked items or the entire list in one tap
- Each user's list is private — enforced with Supabase Row Level Security, not just app logic

## Tech stack

- HTML, CSS, JavaScript (no framework)
- [Supabase](https://supabase.com/) for auth and the database
- Deployed on [Vercel](https://vercel.com/)

## Why I built it

A lightweight, no-friction way to create and share grocery lists without the bloat of full note-taking or task-management apps. Focus on the essentials: categories, checkboxes, quantities, and a way to save groceries from recipes for future shopping.
